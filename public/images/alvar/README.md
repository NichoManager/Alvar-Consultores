# Imágenes reales pendientes

Colocar aquí, en WebP o AVIF y con dimensiones optimizadas:

- `hero-inmobiliaria-madrid.webp`: fotografía horizontal de arquitectura o interior real/autorizado.
- `equipo-alvar-consultores.webp`: retrato profesional real del responsable o equipo.
- `oficina-madrid.webp`: fotografía real de la oficina si representa fielmente el espacio.

La interfaz usa composiciones CSS provisionales hasta disponer de estos recursos.
