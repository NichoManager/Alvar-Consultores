# Alvar Consultores Inmobiliarios

Web corporativa inmobiliaria creada con React, Vite, TypeScript, Tailwind CSS y React Router.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

## Contenido pendiente antes de producción

- Sustituir composiciones arquitectónicas provisionales por fotografías reales autorizadas.
- Conectar formularios con un backend o CRM y revisar el consentimiento.
- Confirmar email corporativo, horario, datos legales y métricas de reseñas.
- Sustituir el catálogo y los artículos demo por contenido validado.
- Configurar mapa, analítica y consentimiento de cookies si se activan servicios externos.

Los inmuebles, artículos y testimonios incluidos están marcados como contenido demo o síntesis editorial.
